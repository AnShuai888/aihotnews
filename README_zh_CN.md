# AIhot · 每日 AI 热点（aihot.space）

一个**零依赖、纯静态**的中文 AI 资讯聚合站点。每天自动抓取 aihot 的 AI 资讯，经去重、分类、评分后生成一份单页日报；每周再聚合一期精选周报。内容由 **Cloudflare Pages** 自动部署，无需后端、无需构建。

- 在线访问：https://aihot.space
- 内容来源：aihot（中文 AI 资讯聚合平台）
- 技术形态：单文件 HTML + 内联 CSS/JS，无 CDN、无外部字体/图片依赖，可离线打开

---

## 这个项目是干什么的

把每天散落在各处的 AI 资讯，整理成一份**结构清晰、可快速浏览**的中文日报。它帮你用最少的时间掌握：今天有哪些新模型/产品发布、行业发生了什么、有哪些值得读的论文、有什么实用技巧。

- 资讯经**同事件去重**（同一件事只保留最重要的 1–2 条），避免刷屏。
- 按**热度评分**排序，默认每类展示 Top 10，也可以切换「全部」。
- 全部附带**来源署名与原文链接**，方便进一步深读。

## 你可以从中获取什么

### 1. 每日 AI 日报（每天更新）

每天聚合过去 24 小时的中文 AI 资讯，固定分为 5 大类，一目了然：

| 分类 | 内容示例 |
| --- | --- |
| **模型** | 新模型发布、版本更新、能力评测 |
| **产品** | AI 应用、工具、平台的上线与迭代 |
| **行业** | 公司动态、投融资、并购、政策监管 |
| **论文** | 前沿研究、arXiv 新作、方法突破 |
| **技巧** | 使用教程、提示词工程、实战经验 |

每张资讯卡片包含：全局连续编号、标题、**热度评分**、来源、**≤60 字中文摘要**、**原文链接**（`target=_blank` 新标签打开）。

### 2. AI 热点榜

日报顶部一份**当日最热事件 Top 榜**（暖橙高亮），一眼抓住当天最值得关注的主线。

### 3. 每周 AI 周报（每周更新）

官网编辑精选，按自然周聚合，分节深度解读一周重点。周报目录以**周期结束日（周日）**命名。

## 如何访问内容

站点按日期归档，URL 规律固定：

- 日报：`https://aihot.space/days/YYYYMMDD/`（例如 `days/20260920/` 表示 2026-09-20 日报）
- 周报：`https://aihot.space/weekly/YYYYMMDD/`（例如 `weekly/20260913/` 表示 2026-09-07 ~ 09-13 那一周）
- 首页：`https://aihot.space/` —— 最新日报入口 + 往期日报 / 周报归档

> 更新频率：日报每个**北京时间**自然日更新；周报在每周结束后数日内发布。

## 技术特性

- **纯静态、零运行时依赖**：单个 HTML 文件内含全部样式与脚本，无构建步骤。
- **原生响应式**：桌面端为「左栏分类导航 + 主区卡片网格」两栏布局；窄屏自动塌缩为顶部导航条。
- **可离线**：无外链资源，下载到本地直接双击即可打开。
- **轻量**：无追踪、无广告、无第三方脚本。

## 本地预览

克隆仓库后，在项目根目录启动任意静态服务器即可：

```bash
python -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765/
```
